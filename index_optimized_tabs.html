数据集管理

对应 data.py 中的数据读取、字段检查、提交记录封装和题目分组逻辑。

数据文件要求

  • java_submissions.csv用于读取提交编号、用户、题目和 Java 源码。
  • distribution_per_question.csv用于统计题目提交数量分布。
  • tst_questions.csv用于补充题目信息统计。

报告生成

输出 report.html、CSV、JSON 和论文统计表，便于论文截图、实验复现和结果归档。

核心输出文件

  • similar_pairs.csv最终高相似代码对。
  • scored_pairs.csv全部候选代码对打分结果。
  • report.html静态可视化报告。
  • paper_tables/论文统计表。

结果查看建议

运行命令后，优先打开 outputs/report.html 查看可视化结果；若要写论文表格，可使用 build-paper-tables 命令生成 CSV。
